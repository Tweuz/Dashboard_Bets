# UA2 – Interface, interação e Affordance

## Objetivo
O objetivo desta atividade foi projetar uma interface que se adapte e se molde aos usuários com deficiência visual, garantindo que essa limitação não os impeça de utilizar a interface e realizar seu trabalho normalmente, conforme o cenário de um artefato gerenciador de cursos internos de uma empresa.

## Solução Desenvolvida
A solução desenvolvida focou na criação de uma interface inclusiva para funcionários da área de treinamento com deficiência visual. As principais características da proposta são:
- **Tipo de Interface Sugerida:** Uma interface gráfica acessível, projetada para funcionar perfeitamente com leitores de tela. A interface deve ser estruturada de forma que os usuários possam navegar por todos os elementos utilizando apenas o teclado.
- **Equipamento Utilizado:** Um computador com teclado e fone de ouvido, acompanhado de um software leitor de tela (como o NVDA). O leitor de tela será responsável por ler em voz alta o conteúdo da tela, permitindo que o usuário interaja com o sistema sem depender da visão.
